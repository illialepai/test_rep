Submit through TikTok

  1. Copy the candidate
  2. Open TikTok in your browser
  3. Change it in TikTok
    On your profile choose Edit profile → Username, select the current username, paste (Ctrl/⌘+V) and press Save. In the phone app: Profile → Edit profile → Username.
  4. Tell the machine what TikTok said
    This app can't see TikTok, so it never marks a username as changed. Only TikTok can confirm it.
